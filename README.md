# Potso Portfolio

A modern, responsive personal portfolio website showcasing my software development projects, technical skills, experience, and journey as a Final-Year Information Technology student.

## Live Website

🌐 **Portfolio:** https://potsoljay.github.io/Potso-Portfolio/

## About

This portfolio serves as my professional online presence, highlighting the projects I have built, the technologies I work with, and my growth as an aspiring software developer.

The website was designed to provide recruiters, lecturers, and collaborators with an easy way to learn more about me, explore my work, and get in touch.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Dark and light mode
- Animated hero section
- Skills showcase
- Professional experience section
- Current learning section
- Project portfolio
- Downloadable CV
- Contact section
- GitHub and LinkedIn integration

## Running the Project Locally

1. Clone the repository.

```bash
git clone https://github.com/PotsoLjay/Potso-Portfolio.git
```

2. Open the project in Visual Studio Code.

3. Open `index.html` in your preferred browser.

No additional installation or dependencies are required.
